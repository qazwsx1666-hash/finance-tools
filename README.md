## 파일 구성

```

styles.css      전체 스타일 (모바일 퍼스트, 토스풍 UI)
app.js          계산 로직 전체 (의존성 없음)
privacy.html    개인정보처리방침 (AdSense 승인 대비)
og-image.png    OpenGraph 공유 이미지 1200×630
```

모든 경로는 `./` 상대 경로라 프로젝트 페이지(`/repo-name/`)든 커스텀 도메인이든 깨지지 않습니다.

## 로컬에서 보기

```bash
cd finance-tools

# 브라우저에서 http://localhost:8000
```

## 배포 (GitHub Pages)

1. 이 저장소의 `Settings → Pages`에서 **Source: Deploy from a branch**, **Branch: `main` / `/ (root)`** 선택 후 저장.
2. 1~2분 뒤 `https://<계정>.github.io/finance-tools/` 에서 확인.

CLI로 활성화하려면:

```bash
gh api -X POST repos/qazwsx1666-hash/finance-tools/pages \
  -f 'source[branch]=main' -f 'source[path]=/'
```

## 배포 후 바꿔야 할 값

`index.html`과 `privacy.html`의 `YOURNAME` 을 실제 주소로 교체하세요.

```html
<link rel="canonical" href="https://qazwsx1666-hash.github.io/finance-tools/">
<meta property="og:url"    content="https://qazwsx1666-hash.github.io/finance-tools/">
<meta property="og:image"  content="https://qazwsx1666-hash.github.io/finance-tools/og-image.png">
```

## Google AdSense 넣는 법

1. `<head>` 안의 주석 처리된 애드센스 스크립트를 풀고 `ca-pub-XXXXXXXXXXXXXXXX` 을 본인 코드로 교체합니다.
2. `<body>` 태그를 `<body class="has-ads">` 로 바꾸면 상단·하단 광고 자리(placeholder)가 보입니다. (기본값은 `display:none`)
3. 각 `<aside class="ad-slot" data-ad-slot="top|bottom">` 안에 `<ins class="adsbygoogle" ...></ins>` 코드를 넣습니다.
4. 광고 단위를 더 넣고 싶으면 계산기 카드 사이에 같은 `aside.ad-slot` 블록을 복사해 붙이면 됩니다.

광고 자리는 레이아웃 이동(CLS)을 막기 위해 `min-height:96px` 를 미리 확보해 두었습니다.
